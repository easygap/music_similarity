        원리

        어떻게 비슷한 곡을 찾나요?

        1. 01

          음악의 특징을 분석합니다

          곡의 앞부분 30초에서 박자, 음량, 음색 등 소리의 특징을 추출합니다.

        2. 02

          등록된 곡과 비교합니다

          단위가 제각각인 값을 StandardScaler로 표준화하고, 카탈로그 전곡과 코사인 유사도를 구해 가까운 순으로 세워요. 지도에서 코랄 점이 기준 곡, 잉크 점이 닮은 곡입니다.

        3. 03

          닮은 부분을 보여드립니다

          추천 곡마다 비슷한 특징을 짚어 드립니다. 그래프와 수치를 함께 보고, 직접 들어 보세요.

        분석 기준 무엇을 근거로 닮았다고 하나요? 어떤 값을 비교하는지 자세히 알아보세요.

        오디오에서 길이를 포함한 58개 값을 추출합니다. 이 중 길이를 뺀 57개 특성으로 유사도를 계산합니다. 템포, 음량, 주파수 특성, 화성·타악 성분, 크로마, MFCC가 포함됩니다.

        각 값을 StandardScaler로 맞춘 뒤 cosine_similarity로 카탈로그 전곡과 비교합니다. 결과는 취향 탐색용 참고 정보이고, 저작권이나 표절 판단의 근거가 될 수는 없어요.
